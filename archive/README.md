|---|---|
| `com_history/` | Change notes, corrections and patch manifests of finished COM work packages (WP2.2, WP2.4, WP2.5-B/C/E), plus the pre-WP2.5 copy of the concurrency contract |
| `patches/` | `.patch` / `.diff` files whose changes are already in `main/` and `components/` |
| `snapshots/` | `backup_before_wp24_m/`, `wp24_m_package/`, and root-level copies of the simulator and WP24-M runner (the live versions are in `tools/`) |
| `test_logs/` | Loose logs from early WP2.2 simulator runs |

Test guides that are still used were moved to `docs/com_tests/`, not here.
